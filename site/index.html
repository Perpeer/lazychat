Chat: your agents, side by side

Every session sits under its project, its terminal next to it. You see which one works, which one waits for you and how long the last prompt took. Press 3 for what each prompt spent: tokens, agents, skills and MCP calls.

Lazy, the mascot

Lazy sits on the side rail and watches every session. It types while an agent works, holds up a ? when one asks you something and celebrates when one is done. Click it to jump to the session that needs you; it lives in the menu bar too, and you get a notification when your terminal is in the background.

Quick start

  1. Run lazychat and name a workspace, the set of projects you work on.
  2. Press o and pick a project folder.
  3. Press n to start Claude Code or Codex in it, Enter to type to it, and ctrl+q to come back.
  4. Tab moves between the tabs, and ? lists every key where you are.

Every key and screen is in the reference.
